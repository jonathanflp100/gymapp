# Prints do app

Telas reais do app (demo), em WebP, usadas nos celulares da página de vendas:
home, treino, evolucao, checkin, relatorio e config.

Para atualizar: tire novos prints da demo (390 × 844), salve com o mesmo nome em .webp.
Se uma imagem faltar, a página mostra um desenho do app no lugar.
